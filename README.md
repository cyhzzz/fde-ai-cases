# FDE 实战案例集

把 AI 落到**具体企业的具体岗位**——三个案例，同一套方法。

在线访问：**https://cyhzzz.github.io/fde-ai-cases/**

---

## 这是什么

这里放的是面向一线业务的 AI 落地推演：不谈模型能力，先看这家企业在哪条产业带、靠什么赚钱，然后从一个岗位一个岗位地问四件事——

1. **接收什么材料**（邮件？表格？图纸？口头？）
2. **做什么判断**（依据是什么、条件是什么、例外怎么办、谁最终确认）
3. **结果交给谁**（下游是谁，他拿这个做什么）
4. **哪一步卡住**（真正让人加班的是哪一步）

答不出这四件事的，就不是一个场景。

**03 是方法演示样张**，分析对象并非本案例集的服务企业，保留仅用于展示方法在 ETO 非标定制场景下怎么走。

## 关于蓝威案例里的「询盘报价演示包」

这是三个案例里唯一做到**文件级**的一套东西。它把"一封客户询盘"到"一份可以发出去的报价"之间的完整过程实体化：

| 环节 | 文件 | 看什么 |
|:---|:---|:---|
| ① 文件怎样进来 | `01-输入·客户询盘-脱敏样例.md` | 客户发来的东西是**残缺的**——18 个报价必需字段只明确了 7 个 |
| ② 中间怎样判断 | `02-规则·报价判断规则表.md` | 20 条规则 + **6 条必须转人工的例外** |
| ③ 结果怎样交付 | `03-交付·询盘信息校验单.md` | 缺什么、找谁补、不补的后果 |
| | `04-交付·报价依据单.md` | **每条结论指回哪条规则、哪行输入** |
| | `05/06-表格·*.csv` | 成本测算表、数量阶梯表（Excel 可直接打开） |
| | `07-交付·中英对照报价单.md` | 客户真正会看到的那一份 |

演示中的**价格量级**参照公开产品页口径（PU 方向盘套 $0.9—$3.5/件），**其余成本项均为构造值**，不代表任何真实报价口径。
